# AULA F75 Knob

Утилита для Windows, которая назначает **любые действия** на ручку клавиатуры
AULA F75: вращение влево/вправо, нажатие и удержание. Работает без драйверов,
без фирменного софта AULA и без установки Python-пакетов — только стандартная
библиотека Python.

В комплекте — локальное меню с тёмным стеклянным интерфейсом: можно выбрать
приложение, громкость которого будет крутить ручка, переназначить действия и
поставить свои обои прямо в программе.

```
вращение влево   → громкость −1
вращение вправо  → громкость +1
короткое нажатие → play/pause
удержание 0.5 с  → mute
Shift + вращение → предыдущий/следующий трек (второй слой)
```

> **Почему Shift, а не «зажатая ручка»?** Фирменный драйвер AULA F75 присылает
> нажатие ручки как мгновенный тап `mute` (15 мс) и не передаёт удержание —
> физическое зажатие ручки прошивка использует для переключения её режима
> (подсветка/громкость). Поэтому «нажатие + вращение» на этой ручке невозможно
> отличить от обычного вращения, и второй слой включается зажатым Shift
> (настраивается в `knob.second_layer_modifier`).

## Меню

Запустите `start.bat` — откроется отдельное окно меню (Edge или Chrome в режиме
приложения, без адресной строки). Если браузер не найден, страница откроется в
браузере по умолчанию.

Разделы меню:

- **Обзор** — что сейчас регулирует ручка и быстрый старт.
- **Громкость** — список приложений с живыми аудиосессиями Windows. Ползунки и
  Mute действуют только на выбранное приложение. Кнопка «Ручка» назначает его
  целью вращения. Системная громкость — отдельный блок.
- **Привязки** — редактор всех шести действий: вращение, нажатие, удержание и
  второй слой (вращение с Shift). Есть «Проверить» для каждого действия.
- **Оформление** — свои обои для окна меню (перетащите файл или выберите),
  затемнение, размытие, акцентный цвет и кнопка «Поставить на рабочий стол».
- **Журнал** — что делает ручка и сервис в реальном времени.

Сервис ручки запускается вместе с меню; его можно остановить и снова запустить
кнопкой в левом нижнем углу. Меню закрывается кнопкой «Закрыть меню» — вместе с
ним останавливается сервис.

Меню слушает только `127.0.0.1` (порт `8765`, при занятости — следующий
свободный), наружу ничего не открывается.

### Громкость только выбранного приложения

Громкость приложений меняется через Windows Core Audio
(`IAudioSessionManager2` / `ISimpleAudioVolume`) — это тот же механизм, что и в
«Микшере громкости» Windows. Ручка трогает только сессии выбранного процесса,
остальные приложения и системная громкость остаются как были.

Системная громкость по-прежнему управляется штатными клавишами `volume up` /
`volume down`, поэтому Windows показывает свой индикатор громкости. Для
приложений индикатор не показывается — уровень виден в меню и в микшере.

Windows создаёт аудиосессию, когда приложение хотя бы раз что-то воспроизвело.
Если приложения нет в списке — запустите в нём музыку или видео и обновите
список. Пока сессии нет, действие громкости для него просто ничего не делает
(в журнале появится запись об этом).

## Требования

- Windows 10/11
- Python 3.9+ (проверено на 3.11) с добавленным в `PATH` `python`/`pythonw`
- Клавиатура AULA F75 в режиме провода или 2.4G (в Bluetooth ручка может
  отправлять другие коды — проверьте через `--learn`)

## Быстрый старт

1. Запустите `start.bat` — откроется меню, сервис ручки стартует автоматически.
2. Во вкладке «Громкость» выберите приложение и нажмите «Ручка» (или введите имя
   процесса вручную и нажмите «Применить к ручке»).
3. Покрутите ручку — меняется громкость только этого приложения.

Без меню, в консоли: `start_headless.bat` (или `python aula_knob.py`).
Остановка: `Ctrl+C` в консоли или `stop.bat`.

Чтобы всё работало в фоне без окна консоли, запускайте `start_hidden.vbs` —
он поднимает меню через `pythonw`. Остановить фоновые процессы — `stop.bat`.

### Автозапуск

Запустите `install_startup.bat` — в папке «Автозагрузка» появится ярлык
`AULA F75 Knob.lnk`, который стартует `start_hidden.vbs` при входе в систему.
Удалить автозапуск — удалить этот ярлык (`Win+R` → `shell:startup`).

## Как это работает

Ручка AULA F75 определяется системой как обычные мультимедийные клавиши
(`volume up`, `volume down`, `volume mute` / `play/pause`). Утилита ставит
низкоуровневый хук `WH_KEYBOARD_LL`, перехватывает эти клавиши и, если
`suppress: true`, не пропускает их в систему — вместо них выполняется ваше
действие. Синтетические нажатия самой утилиты помечаются в `dwExtraInfo`
(`INJECT_TAG`), и хук их игнорирует, поэтому рекурсии нет.

### Если установлен фирменный софт AULA

Драйвер `C:\Program Files (x86)\AULA\F75\OemDrv.exe` (и его службы) читает
энкодер ручки и **сам эмулирует** мультимедиа-клавиши через `SendInput`. Такие
события приходят в хук с флагом `LLKHF_INJECTED`, поэтому утилита обрабатывает
их так же, как настоящие нажатия: перехватывает, подавляет и выполняет вашу
привязку. Без этого родные клавиши драйвера доходили бы до Windows и меняли
общую громкость/выключали весь звук вместо выбранного приложения.

Свои синтетические нажатия утилита отличает по метке `dwExtraInfo` и никогда
не перехватывает — поэтому системная громкость и медиа-клавиши из действий
(`volume` без `app`, `media`) работают как раньше.

Побочный эффект: при `suppress: true` перехватываются и любые другие
программные (`SendInput`) нажатия этих же клавиш. Если какая-то программа
управляет громкостью через эмуляцию клавиш, её нажатия тоже не дойдут до
системы — на время работы утилиты. Физические клавиши клавиатуры работают как
обычно.

Права администратора не нужны. Если вы хотите управлять окном приложения,
запущенного от администратора, запустите утилиту тоже от администратора
(ограничение UIPI для `SendInput`).

## config.json

```jsonc
{
  "knob": {
    // Не пропускать родные действия ручки в систему.
    "suppress": true,

    // Сколько миллисекунд держать ручку, чтобы сработало "hold".
    "hold_ms": 500,

    // Склеивать повороты, приходящие чаще, чем раз в N мс (0 — не склеивать).
    // Полезно, если ручка за один щелчок присылает два события.
    "merge_rotation_ms": 0,

    // Клавиша-модификатор для второго слоя (held_rotate_*): вращение с зажатым
    // Shift/ctrl/alt выполняет действия из held_rotate_*. "none" — только
    // реально зажатая ручка (работает не на всех прошивках).
    "second_layer_modifier": "shift",

    // Клавиши, которые присылает ручка. Смотрите их через --learn.
    "rotate_left_keys": ["volume down"],
    "rotate_right_keys": ["volume up"],
    "press_keys": ["volume mute", "play/pause"]
  },

  // Минимальная пауза между повторными срабатываниями одной привязки, мс.
  "cooldown_ms": 0,

  // Необязательный лог в файл (например "knob.log").
  "log_file": null,

  "bindings": {
    // Вращение без нажатия.
    "rotate_left":  { "type": "volume", "delta": -1 },
    "rotate_right": { "type": "volume", "delta": 1 },

    // Короткое нажатие и удержание.
    "press": { "type": "media", "action": "play_pause" },
    "hold":  { "type": "media", "action": "mute" },

    // Второй слой: вращение с зажатым Shift (second_layer_modifier).
    "held_rotate_left":  { "type": "media", "action": "prev" },
    "held_rotate_right": { "type": "media", "action": "next" }
  }
}
```

`bindings` может содержать не все ключи: `hold` и `held_rotate_*`
необязательны. Если `hold` не задан, удержание ничем не отличается от нажатия.
Если `held_rotate_*` не заданы, при зажатом модификаторе используются обычные
`rotate_left`/`rotate_right`.

### Типы действий

Действие — это объект с полем `type`. Вместо объекта можно использовать
список действий (выполнятся по порядку).

| type | Поля | Пример |
| --- | --- | --- |
| `keys` | `keys` (строка или список), `repeat`, `interval_ms` | `{"type":"keys","keys":"ctrl+shift+m"}` |
| `text` | `text` | `{"type":"text","text":"Привет"}` |
| `command` | `cmd` (строка или список), `shell`, `hidden`, `cwd`, `wait` | `{"type":"command","cmd":"notepad"}` |
| `open` | `target` (файл/папка/URI), необязательный `args` | `{"type":"open","target":"C:\\Users"}` |
| `url` | `url` | `{"type":"url","url":"https://youtube.com"}` |
| `media` | `action`: `play_pause`, `next`, `prev`, `stop`, `mute` | `{"type":"media","action":"next"}` |
| `volume` | `delta`, `step` (по умолчанию 2 %), `level`, `app`, `interval_ms` | `{"type":"volume","delta":1,"app":"Discord.exe"}` |
| `mute` | `app`, `state`: `toggle`, `on`, `off` | `{"type":"mute","app":"Discord.exe"}` |
| `wheel` | `delta` (щелчки), `horizontal` | `{"type":"wheel","delta":-3}` |
| `focus` | `title` (подстрока заголовка окна) | `{"type":"focus","title":"Discord"}` |
| `sleep` | `ms` | `{"type":"sleep","ms":200}` |
| `none` | — | `{"type":"none"}` |

`volume` без поля `app` — системная громкость (штатные клавиши Windows).
С полем `app` — громкость только этого приложения; `delta` считается шагами
по `step` процентов. Если задан `level`, громкость сразу ставится на это
значение (0–100).

Для любой привязки можно добавить `"cooldown_ms": 300` — индивидуальная пауза
между срабатываниями.

### Примеры

Фрагменты ниже вставляются внутрь объекта `"bindings"`.

Ручка меняет громкость только Discord, нажатие — mute Discord:

```json
"rotate_left":  { "type": "volume", "delta": -1, "step": 2, "app": "Discord.exe" },
"rotate_right": { "type": "volume", "delta": 1, "step": 2, "app": "Discord.exe" },
"press": { "type": "mute", "app": "Discord.exe", "state": "toggle" }
```

Громкость браузера шагом 5 %, а удержание — mute системы:

```json
"rotate_left":  { "type": "volume", "delta": -1, "step": 5, "app": "chrome.exe" },
"rotate_right": { "type": "volume", "delta": 1, "step": 5, "app": "chrome.exe" },
"hold": { "type": "mute", "state": "toggle" }
```

Запуск Discord по нажатию, YouTube — по удержанию:

```json
"press": { "type": "open", "target": "discord://" },
"hold":  { "type": "url",  "url": "https://youtube.com" }
```

Горячие клавиши и текст:

```json
"press": { "type": "keys", "keys": "ctrl+shift+m" },
"hold":  { "type": "keys", "keys": "win+d" },
"held_rotate_right": { "type": "text", "text": "hello" }
```

Прокрутка страницы вместо громкости:

```json
"rotate_left":  { "type": "wheel", "delta": 3 },
"rotate_right": { "type": "wheel", "delta": -3 },
"held_rotate_left":  { "type": "keys", "keys": "alt+left" },
"held_rotate_right": { "type": "keys", "keys": "alt+right" }
```

Открыть папку и сфокусировать окно:

```json
"press": {
  "type": "command",
  "cmd": "explorer.exe C:\\Users\\Public\\Downloads"
},
"hold": { "type": "focus", "title": "Discord" }
```

Несколько действий сразу:

```json
"press": [
  { "type": "focus", "title": "Discord" },
  { "type": "keys", "keys": "ctrl+shift+m" }
]
```

## Обои меню

Вкладка «Оформление»:

- перетащите картинку в область загрузки или нажмите на неё;
- поддерживаются PNG, JPG, WEBP, GIF и BMP до 30 МБ;
- ползунки «Затемнение» и «Размытие» помогают сохранить читаемость текста;
- акцентный цвет меняет подсветку всего интерфейса;
- «Убрать обои» возвращает градиентный фон;
- «Поставить на рабочий стол» ставит ту же картинку обоями Windows.

Обои хранятся в папке `wallpapers`, настройки интерфейса — в `ui.json`.

## Настройка под свою ручку

1. Остановите утилиту (`stop.bat`).
2. Запустите `python aula_knob.py --learn`.
3. Покрутите ручку влево, вправо, нажмите её. В консоли появятся строки вида:

   ```
   down  VK=0xAF (175)  scan=0x30  flags=0x00  volume up
   ```

4. Впишите имена (`volume up`, `volume down`, `play/pause`, ..., либо `vk:0xAF`)
   в `knob.rotate_left_keys`, `knob.rotate_right_keys`, `knob.press_keys`.
5. Проверьте: `python aula_knob.py --check`, затем запустите обычный режим.

Если ручка присылает одну и ту же клавишу на поворот в разные стороны —
увы, прошивка не различает направление; можно повесить одно действие.

## Частые вопросы

**Приложения нет в списке громкости.** Windows создаёт аудиосессию, только когда
приложение что-то воспроизводит. Включите в нём звук и обновите список.

**Громкость меняется дважды.** Значит `suppress: false`, и системная реакция
складывается с действием. Поставьте `"suppress": true`.

**Ручка меняет общую громкость Windows, а не выбранного приложения.**
Долго было из-за фирменного драйвера AULA (`OemDrv.exe`): он эмулирует
мультимедиа-клавиши ручки, а утилита такие «инжектированные» события
игнорировала — они доходили до Windows и меняли общую громкость (и выключали
весь звук при нажатии). Теперь такие события перехватываются и подавляются.
Если поведение осталось — перезапустите меню/утилиту (обновите её) и проверьте
журнал: при вращении там должны появляться строки `rotate_right: громкость
для ...`.

**Не срабатывают действия в приложении от администратора.** Запустите утилиту
от администратора.

**Ручка перестала менять громкость совсем.** Проверьте, что сервис запущен
(индикатор в меню) и что в конфиге нет ошибок (`--check`). Пока утилита
работает, она намеренно забирает эти клавиши себе.

**Нажатие + вращение не переключает трек.** Так и задумано на AULA F75:
фирменный драйвер присылает нажатие ручки мгновенным тапом `mute` (15 мс), а
удержание вообще не передаёт — физическое зажатие ручки прошивка использует
для переключения её режима (подсветка/громкость). Софт не может узнать, что
ручка зажата, поэтому второй слой включается модификатором: **зажмите Shift и
покрутите ручку**. Модификатор меняется в `knob.second_layer_modifier`
(`shift`, `ctrl`, `alt` или `none`). Кнопка «Проверить» в меню проверяет само
действие и работает независимо от ручки.

**Меню не открылось.** Запустите `python menu.py` в консоли — там будет адрес
(`http://127.0.0.1:8765/`). Откройте его в браузере вручную.

**Хочу вернуть поведение «как было».** Остановите утилиту или поставьте
`"suppress": false` — тогда системные действия останутся, а ваши добавятся.

**Утилита уже запущена.** Второй экземпляр не стартует (мьютекс). Остановите
первый через `stop.bat`. Меню тоже одно: повторный запуск сообщит, что оно уже
открыто.
