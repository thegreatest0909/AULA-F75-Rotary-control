# AULA F75 Knob

Нативное Windows-приложение, которое назначает **любые действия** на ручку
клавиатуры AULA F75: вращение влево/вправо, нажатие и второй слой с Shift.
Оформление — тёмное «стеклянное» меню, но это обычное окно программы, а не
браузер: внутри встроенный WebView2, без локального сервера, портов и адресов.

```
вращение влево   → громкость выбранного приложения −1
вращение вправо  → громкость выбранного приложения +1
короткое нажатие → mute выбранного приложения
Shift + вращение → предыдущий/следующий трек (второй слой)
```

Программа умеет работать в фоне и **сворачиваться в системный трей**: при
закрытии окна сервис ручки продолжает работать, а окно открывается кликом по
иконке в трее.

> **Почему Shift, а не «зажатая ручка»?** Фирменный драйвер AULA превращает
> нажатие ручки в мгновенный тап `mute` (~15 мс) и не передаёт удержание —
> физическое зажатие ручки прошивка использует для переключения её режима
> (подсветка/громкость). Поэтому «нажатие + вращение» на F75 невозможно
> отличить от обычного вращения, и второй слой включается зажатым Shift.
> Модификатор настраивается в `knob.second_layer_modifier` (`shift`, `ctrl`,
> `alt` или `none`).

## Возможности

- Громкость и mute **только выбранного приложения** через Windows Core Audio —
  остальные приложения и системная громкость не трогаются.
- Любые действия на жесты: горячие клавиши, запуск программ, открытие ссылок и
  папок, медиа, прокрутка, фокус окна, текст, команды — всё из `config.json`.
- Живой журнал: видно каждое срабатывание и ошибки.
- Свои обои для окна, затемнение, размытие и акцентный цвет; кнопка «поставить
  на рабочий стол».
- Работа в трее, автозапуск при входе, один экземпляр программы.
- Только локальные действия: никакой сети, телеметрии и «облака».

## Установка

1. Скачайте `AULA-F75-Knob-Setup-1.0.1.exe` со страницы
   [Releases](https://github.com/thegreatest0909/AULA-F75-Rotary-control/releases).
2. Запустите его — установка идёт в профиль пользователя
   (`%LOCALAPPDATA%\Programs\AULA F75 Knob`), права администратора не нужны.
3. Запустите «AULA F75 Knob» из меню «Пуск». Программа появится в трее, окно
   можно открыть кликом по иконке.

Портативный вариант — тот же `AULA-F75-Knob.exe` без установки.

### Запуск из исходников

```bat
python -m pip install -r requirements.txt
python app.py
```

Нужен Python 3.9+ (проверено на 3.11) и компонент WebView2 — на Windows 10/11
он обычно уже установлен вместе с Edge.

## Интерфейс

- **Обзор** — что сейчас регулирует ручка и что делают жесты.
- **Громкость** — список приложений с живыми аудиосессиями Windows. Ползунки и
  Mute действуют только на выбранное приложение. Кнопка «Ручка» назначает его
  целью вращения. Системная громкость — отдельный блок.
- **Привязки** — редактор всех шести действий: вращение, нажатие, удержание и
  второй слой (вращение с Shift). Есть «Проверить» для каждого действия.
- **Оформление** — свои обои для окна (перетащите файл или выберите),
  затемнение, размытие, акцентный цвет и кнопка «Поставить на рабочий стол».
- **Журнал** — что делают ручка и сервис в реальном времени.
- **Трей** — иконка в системном трее: открыть/скрыть окно и выход.

Кнопка «Закрыть меню» в окне полностью останавливает программу. Закрытие окна
крестиком сворачивает её в трей — сервис при этом продолжает работать. Выход
также доступен из меню иконки в трее.

## Как это работает

Ручка AULA F75 определяется системой как обычные мультимедийные клавиши
(`volume up`, `volume down`, `volume mute` / `play/pause`). Утилита ставит
низкоуровневый хук `WH_KEYBOARD_LL`, перехватывает эти клавиши и, если
`suppress: true`, не пропускает их в систему — вместо них выполняется ваше
действие.

Синтетические нажатия самой утилиты помечаются в `dwExtraInfo` (`INJECT_TAG`),
и хук их игнорирует, поэтому рекурсии нет.

### Если установлен фирменный софт AULA

Драйвер AULA (например, `OemDrv.exe` из `C:\Program Files (x86)\AULA\F75`) или
фирменная панель клавиатуры читает энкодер ручки и **сам эмулирует**
мультимедиа-клавиши через `SendInput`. Такие события приходят в хук с флагом
`LLKHF_INJECTED`, и утилита обрабатывает их так же, как настоящие нажатия:
перехватывает, подавляет и выполняет вашу привязку. Без этого родные клавиши
драйвера доходили бы до Windows и меняли общую громкость/выключали весь звук
вместо выбранного приложения.

Побочный эффект: при `suppress: true` перехватываются и любые другие
программные (`SendInput`) нажатия этих же клавиш, пока программа запущена.
Физические клавиши клавиатуры работают как обычно.

Права администратора не нужны. Если вы хотите управлять окном приложения,
запущенного от администратора, запустите программу тоже от администратора
(ограничение UIPI для `SendInput`).

## config.json

Настройки хранятся в `%APPDATA%\AULA F75 Knob\config.json` (установленная
версия) или рядом с `app.py` (запуск из исходников).

```jsonc
{
  "knob": {
    // Не пропускать родные действия ручки в систему.
    "suppress": true,

    // Сколько миллисекунд держать ручку, чтобы сработало "hold".
    "hold_ms": 500,

    // Склеивать повороты, приходящие чаще, чем раз в N мс (0 — не склеивать).
    "merge_rotation_ms": 0,

    // Клавиша-модификатор для второго слоя (held_rotate_*).
    "second_layer_modifier": "shift",

    // Клавиши, которые присылает ручка. Смотрите их через --learn.
    "rotate_left_keys": ["volume down"],
    "rotate_right_keys": ["volume up"],
    "press_keys": ["volume mute", "play/pause"]
  },

  // Минимальная пауза между повторными срабатываниями одной привязки, мс.
  "cooldown_ms": 0,

  // Необязательный лог в файл (например "knob.log").
  "log_file": null,

  "bindings": {
    // Вращение без модификатора.
    "rotate_left":  { "type": "volume", "delta": -1 },
    "rotate_right": { "type": "volume", "delta": 1 },

    // Короткое нажатие и удержание.
    "press": { "type": "media", "action": "play_pause" },
    "hold":  { "type": "media", "action": "mute" },

    // Второй слой: вращение с зажатым Shift (second_layer_modifier).
    "held_rotate_left":  { "type": "media", "action": "prev" },
    "held_rotate_right": { "type": "media", "action": "next" }
  }
}
```

`bindings` может содержать не все ключи: `hold` и `held_rotate_*`
необязательны. Если `hold` не задан, удержание ничем не отличается от нажатия.
Если `held_rotate_*` не заданы, при зажатом модификаторе используются обычные
`rotate_left`/`rotate_right`.

### Типы действий

Действие — это объект с полем `type`. Вместо объекта можно использовать
список действий (выполнятся по порядку).

| type | Поля | Пример |
| --- | --- | --- |
| `keys` | `keys` (строка или список), `repeat`, `interval_ms` | `{"type":"keys","keys":"ctrl+shift+m"}` |
| `text` | `text` | `{"type":"text","text":"Привет"}` |
| `command` | `cmd` (строка или список), `shell`, `hidden`, `cwd`, `wait` | `{"type":"command","cmd":"notepad"}` |
| `open` | `target` (файл/папка/URI), необязательный `args` | `{"type":"open","target":"C:\\Users"}` |
| `url` | `url` | `{"type":"url","url":"https://youtube.com"}` |
| `media` | `action`: `play_pause`, `next`, `prev`, `stop`, `mute` | `{"type":"media","action":"next"}` |
| `volume` | `delta`, `step` (по умолчанию 2 %), `level`, `app`, `interval_ms` | `{"type":"volume","delta":1,"app":"Discord.exe"}` |
| `mute` | `app`, `state`: `toggle`, `on`, `off` | `{"type":"mute","app":"Discord.exe"}` |
| `wheel` | `delta` (щелчки), `horizontal` | `{"type":"wheel","delta":-3}` |
| `focus` | `title` (подстрока заголовка окна) | `{"type":"focus","title":"Discord"}` |
| `sleep` | `ms` | `{"type":"sleep","ms":200}` |
| `none` | — | `{"type":"none"}` |

`volume` без поля `app` — системная громкость (штатные клавиши Windows).
С полем `app` — громкость только этого приложения; `delta` считается шагами
по `step` процентов. Если задан `level`, громкость сразу ставится на это
значение (0–100).

Для любой привязки можно добавить `"cooldown_ms": 300` — индивидуальная пауза
между срабатываниями.

### Примеры

Фрагменты ниже вставляются внутрь объекта `"bindings"`.

Ручка меняет громкость только Discord, нажатие — mute Discord:

```json
"rotate_left":  { "type": "volume", "delta": -1, "step": 2, "app": "Discord.exe" },
"rotate_right": { "type": "volume", "delta": 1, "step": 2, "app": "Discord.exe" },
"press": { "type": "mute", "app": "Discord.exe", "state": "toggle" }
```

Громкость браузера шагом 5 %, а удержание — mute системы:

```json
"rotate_left":  { "type": "volume", "delta": -1, "step": 5, "app": "chrome.exe" },
"rotate_right": { "type": "volume", "delta": 1, "step": 5, "app": "chrome.exe" },
"hold": { "type": "mute", "state": "toggle" }
```

Запуск Discord по нажатию, YouTube — по удержанию:

```json
"press": { "type": "open", "target": "discord://" },
"hold":  { "type": "url",  "url": "https://youtube.com" }
```

Горячие клавиши и текст:

```json
"press": { "type": "keys", "keys": "ctrl+shift+m" },
"hold":  { "type": "keys", "keys": "win+d" },
"held_rotate_right": { "type": "text", "text": "hello" }
```

Прокрутка страницы вместо громкости:

```json
"rotate_left":  { "type": "wheel", "delta": 3 },
"rotate_right": { "type": "wheel", "delta": -3 },
"held_rotate_left":  { "type": "keys", "keys": "alt+left" },
"held_rotate_right": { "type": "keys", "keys": "alt+right" }
```

Открыть папку и сфокусировать окно:

```json
"press": {
  "type": "command",
  "cmd": "explorer.exe C:\\Users\\Public\\Downloads"
},
"hold": { "type": "focus", "title": "Discord" }
```

Несколько действий сразу:

```json
"press": [
  { "type": "focus", "title": "Discord" },
  { "type": "keys", "keys": "ctrl+shift+m" }
]
```

### Краткая запись в `--do`

```
keys:ctrl+alt+t
text:hello
run:notepad
open:C:\Users
url:https://example.com
media:next
volume:-2
wheel:3
focus:Discord
sleep:500
```

## Автозапуск

Запустите `install_startup.bat` — в папке автозагрузки появится ярлык
`AULA F75 Knob.lnk`, который при входе в систему запускает программу свёрнутой
в трей. Для установленной версии можно вручную положить ярлык на
`AULA F75 Knob.exe` с параметром `--minimized` в папку автозагрузки.
Удалить автозапуск — удалить ярлык (`Win+R` → `shell:startup`).

## Частые вопросы

**Ручка меняет общую громкость Windows, а не выбранного приложения.**
Фирменный драйвер AULA эмулирует мультимедиа-клавиши через `SendInput`; раньше
такие события игнорировались. Теперь они перехватываются и подавляются.
Проверьте, что запущена свежая версия и в журнале при вращении появляются
строки `rotate_right: громкость для ...`.

**Нажатие + вращение не переключает трек.** Так и задумано на AULA F75:
драйвер присылает нажатие мгновенным тапом, а удержание вообще не передаёт —
прошивка использует зажатие ручки для переключения её режима. Зажмите **Shift**
и покрутите ручку. Модификатор меняется в `knob.second_layer_modifier`.

**Приложения нет в списке громкости.** Windows создаёт аудиосессию, только
когда приложение что-то воспроизводит. Включите в нём звук и обновите список.

**Закрыл окно, а звук продолжает регулироваться.** Так и должно быть: окно
свернулось в трей, сервис работает. Откройте окно кликом по иконке в трее или
выйдите через «Выход».

**Окно не открывается / пустое.** Убедитесь, что установлен компонент
WebView2 (на Windows 10/11 обычно уже есть вместе с Edge). При запуске из
исходников поставьте зависимости: `python -m pip install -r requirements.txt`.

**Не срабатывают действия в приложении от администратора.** Запустите
программу от администратора.

**Хочу вернуть поведение «как было».** Остановите программу или поставьте
`"suppress": false` — тогда системные действия останутся, а ваши добавятся.

**Где хранятся настройки.** Установленная версия: `%APPDATA%\AULA F75 Knob\`
(`config.json`, `ui.json`, `wallpapers\`). Запуск из исходников — рядом с
`app.py`.

**Программа уже запущена.** Второй экземпляр не стартует — окно открывается из
трея.
